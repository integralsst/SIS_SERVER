# No aplica

El dominio `no-aplica` conserva la decisión separada de `EvaluacionAspecto`.

Flujo:

1. El PROFESIONAL registra `NO_APLICA` con justificación dentro de una gestión.
2. Al finalizar se crea `DecisionNoAplica` en `PENDIENTE` con resultado efectivo 3.
3. El COORDINADOR decide.
4. Aprobado produce resultado efectivo 5; rechazado produce 0.
5. La evaluación original no se modifica.
